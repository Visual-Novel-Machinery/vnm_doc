# Changelog:

## Features:
- added support for fading in and out of Audio
- added support for displaying the character text left/right/center
- Added ability to flip character images and added support for custom 2d character positioning
- added support for z order index managing for characters
- added auto save file system to save game system. This can be configured to to automatic time intervals or manual
- Added support for rolling back dialog

## Bug Fixes:
- added safety check if image definition has a null image, to prevent a crash
- Remove sub dialog system
- fixed pop up button texts in example ui
